# RK3588 整套系统移植教程

> 把 FThand 遥操整套（ROS2 工程 + 上位机 HDService + 全部配置）从当前板子搬到**另一块 RK3588**。
> 本教程假设新板子和当前一样：Ubuntu 20.04 + ROS2 Foxy。若新板子系统不同，见末尾「系统不同的情况」。
> 参考：`RK3588移植实录.md`（怎么一步步做出来的）、`RK3588使用手册.md`（怎么用）。

---

## 0. 要搬什么（一张清单）

| 要搬的东西 | 内容 | 放哪 |
|---|---|---|
| `FThand` | FT_core（orca_core + models + teleoperation.py 等） | `~/FThand/FThand/FT_core` |
| `fthand_ws` | ROS2 工作空间（orcahand_teleop_ros2 包，6 个节点） | `~/fthand_ws/src` |
| `HDW` | HandDriver Web 上位机（HDService 二进制 + Web 客户端） | `~/HDW` |
| `protobuf3124` | HDService 依赖的 `libprotobuf.so.23` | `~/protobuf3124/lib` |
| `run_hdservice.sh` | 上位机启动脚本（含 LD_LIBRARY_PATH） | `~/run_hdservice.sh` |

> 源可以是当前板子（最省事），也可以是 Windows 桌面源 `C:\...\FThand\FThand`。

## 1. 新板子环境准备

```bash
# ① 确认系统（决定 ROS2 版本）
cat /etc/os-release | grep PRETTY_NAME

# ② 装 ROS2 Foxy（若没有）+ 编译工具
sudo apt update
sudo apt install -y ros-foxy-desktop python3-colcon-common-extensions

# ③ 装 Python 依赖（用 apt，别用 pip——numpy 版本坑）
sudo apt install -y python3-serial python3-yaml python3-numpy

# ④ 串口权限（手/接收器是 USB 串口）
sudo usermod -aG dialout $USER     # 加完注销重登
```

## 2. 拷贝代码（从当前板子 192.168.110.44）

在新板子上跑（或从 Windows scp）：
```bash
# 从当前板子拷（旧板子 IP 填你现在的）
scp -r ubuntu@192.168.110.44:~/fthand_ws/src ~/fthand_ws/
scp -r ubuntu@192.168.110.44:~/FThand ~/
scp -r ubuntu@192.168.110.44:~/HDW ~/
scp -r ubuntu@192.168.110.44:~/protobuf3124/lib ~/protobuf3124/    # 只拷 lib/（.so，~10MB）
scp ubuntu@192.168.110.44:~/run_hdservice.sh ~/
```

> ⚠️ 只拷 `protobuf3124/lib/`（.so 文件），别整目录（751MB 含静态库）。
> 目录结构必须保持：`~/FThand/FThand/FT_core`、`~/fthand_ws/src`——节点靠这些路径解析。

## 3. ROS2 工程构建 + 环境

```bash
# ① 验证导入（Python 3.8 兼容）
cd ~/FThand/FThand/FT_core
python3 -c "from orca_core.core import OrcaHand; from teleoperation import GloveToHandMapper; print('导入OK')"

# ② 构建
source /opt/ros/foxy/setup.bash
cd ~/fthand_ws
colcon build --packages-select orcahand_teleop_ros2 --symlink-install

# ③ 自动 source（新终端生效）
echo "source ~/fthand_ws/install/setup.bash" >> ~/.bashrc
echo '[ -f ~/fthand_ws/install/setup.bash ] && source ~/fthand_ws/install/setup.bash' >> ~/.profile

# ④ 验证
source install/setup.bash
ros2 pkg executables orcahand_teleop_ros2   # 应看到 6 个节点
```

## 4. 上位机 HDService（核心坑：libprotobuf）

新板子如果也是 **Ubuntu 20.04**，`libprotobuf.so.23` 用第 2 步拷的就行。若没拷，按 `RK3588移植实录.md` Phase 5 从源码编（约 10 分钟）或下载 jammy deb（**仅 22.04+ 可用**，20.04 glibc 2.31 太旧）。

```bash
# ① 改 run_hdservice.sh 里的用户路径（如果用户名不是 ubuntu）
sed -i 's|/home/ubuntu|/home/<你的用户名>|g' ~/run_hdservice.sh

# ② 测试启动（没插接收器也能起）
bash ~/run_hdservice.sh
#   看到 "UDP Data Stream started from saved config." 就对了，Ctrl+C 停
#   ⚠️ UDP 配置会从 HDW/log 里带过来（发到 127.0.0.1:8000），不用重配
```

---

## 5. 硬件配置（固定串口，防拔插变号）

```bash
# ① 插上手 + 接收器，看编号
ls -l /dev/ttyACM*

# ② 装 udev 固定软链接（手 CH343 → /dev/orcahand_serial）
sudo bash -c 'cat > /etc/udev/rules.d/99-orcahand.rules <<EOF
KERNEL=="ttyACM*", SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="55d3", SYMLINK+="orcahand_serial", MODE="0666"
EOF'
sudo udevadm control --reload-rules && sudo udevadm trigger
sleep 2 && ls -l /dev/orcahand_serial     # 应指向 ttyACMx

# ③ config.yaml 端口（左右手都改）
sed -i 's|^port:.*|port: /dev/orcahand_serial|' ~/FThand/FThand/FT_core/orca_core/models/orcahand_v1_left/config.yaml
sed -i 's|^port:.*|port: /dev/orcahand_serial|' ~/FThand/FThand/FT_core/orca_core/models/orcahand_v1_right/config.yaml
```

## 6. 开机自启（systemd）

```bash
# ① HDService 自启（服务端，安全）
sudo bash -c 'cat > /etc/systemd/system/hdservice.service <<EOF
[Unit]
Description=HandDriver Web Server
After=network.target
[Service]
Type=simple
User=<你的用户名>
Environment=HOME=/home/<你的用户名>
ExecStart=/bin/bash /home/<你的用户名>/run_hdservice.sh
Restart=always
RestartSec=3
[Install]
WantedBy=multi-user.target
EOF'
sudo systemctl daemon-reload && sudo systemctl enable hdservice && sudo systemctl start hdservice
systemctl is-active hdservice    # 应 active

# ② 遥操【不】自启（防止上电手自动动）——保持手动
```

## 8. 需要改的（新板子专属）

| 项 | 改法 |
|---|---|
| 板子 IP | 换 DHCP 或固定，Windows 监控用新 IP |
| 用户名 | 所有 `/home/ubuntu` → `/home/<你的用户名>` |
| config.yaml 端口 | 已用固定软链接，不用改 |
| 手套 UDP 目标 | HDService 配置从 HDW/log 带过来，指向 127.0.0.1:8000，不用改 |

## 9. 系统不同的情况

- **Ubuntu 22.04 + Humble**：`python3-numpy` 版本 OK；节点代码基本兼容；`ros2 topic echo --once` 可用
- **Ubuntu 24.04 + Jazzy**（如 Jetson）：`libprotobuf.so.23` 直接用 jammy deb（glibc 够新）；代码已验证兼容（见 Jetson 移植）
- 只要 `ros2 pkg executables` 6 个节点齐 + HDService 能起 + `/dev/orcahand_serial` 在，就搬好了
